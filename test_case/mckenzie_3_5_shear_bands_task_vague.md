# 用例 3.5（模糊版）：剪切带自发形成

## 需求

我想模拟部分熔融的岩石在简单剪切下自发形成低角度剪切带（孔隙局部化）。2D 就行，你帮我用 ASPECT 搭好。

## 请你处理

数值细节我没给，也不会给——这正是要考验你的地方。请你：

1. 结合该问题在文献里的标准做法（必要时检索 RAG 案例库 / ASPECT 参数定义），把盒子尺寸、网格、粘度本构（注意：没有"孔隙弱化"就长不出剪切带）、密度、重力、边界条件、初始扰动、时间步与 CFL、运行时长、后处理等**全部参数**定出来；
2. 对每一个"我没有明确告诉你、只能靠你假设补齐"的参数，明确写出来：**它是什么、你给了什么值、依据是什么**（ASPECT 默认值 / 文献惯例 / 合理假设）；
3. 最终产出一个能跑通的 `.prm` 文件，并实际运行验证。

## 期望结果（提示，不是标准答案）

均匀背景上自发长出低角度（约 15–30°）的富熔体剪切带，涡度扰动集中在带内。
