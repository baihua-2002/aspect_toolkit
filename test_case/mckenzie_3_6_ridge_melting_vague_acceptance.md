# 模糊版验收标准：3.6 二维洋中脊熔体生成与运移

> 仅评分用，**不得**作为 agent 输入。真值参考：`mckenzie_3_6_ridge_melting_answers.json`。

## 物理判别特征（必须出现）

1. **板块扩张**：顶边左右两半对称分离速度（如左 u=-1、右 u=+1），其余边自由滑移；
2. **熔融源项**：强制绝热熔融 Γ = ρ_s · W · dF/dz（imposed 线性熔融函数 F(z)）；
3. 底热顶冷（T_bot=1, T_top=0）+ 线性初始温度剖面；
4. 脊轴下方形成**高孔隙度熔体通道**，固体流线对称上涌、熔体流线向脊轴汇聚。

## 允许的参数范围（合理假设）

| 参数 | 允许区间 | 说明 |
|------|---------|------|
| 几何 | 半宽 ~4、深度 ~3（无量纲，X 4–8、Y 2–4） | |
| 顶边速度 | 对称分离，|u| ≈ 1 | 无扩张速度 → 无熔体通道 |
| 熔融函数 | F_max ≈ 1、熔融深度 d ≈ 3（与盒深同量级） | 不设熔融 → 特征 2/4 失败 |
| 粘度 η / 密度 ρ | ~1 | |
| CFL | < 0.5（建议 0.3），dt ≤ 0.5 | |
| 网格 | 全局加密 ≥ 3 级 + 自适应 | 通道需要分辨率 |
| 运行时长 | t_end ≈ 10 | 太短熔体聚焦未形成 |
| 后处理 | visualization + velocity + temperature statistics | |

## 关键失败信号

- 顶边是自由滑移而非对称扩张 → 无熔体通道，特征 1/4 失败；
- 无熔融源项 → 只有被动孔隙度，特征 2 失败；
- 运行过短 → 熔体未聚焦。

## 评分权重

运行成功 30 / 判别特征 30 / 参数合理性 20 / 假设披露 20。
