# 模糊版验收标准：3.4 岩浆孤立波传播

> 仅评分用，**不得**作为 agent 输入。真值参考：`mckenzie_3_4_solitary_wave_answers.json`。

## 物理判别特征（必须出现）

1. **细长盒子**（X ≪ Y，近似 1D 传播），纵向高分辨率网格；
2. 重力竖直向下 ~1（浮力驱动波传播），等粘度，渗透率 K = φⁿ（n≈3）幂律；
3. 初始为均匀背景 + 孤立波扰动，波以**恒定相速度、固定形态**传播（Barcilon & Richter 1986 解析解）。

## 允许的参数范围（合理假设）

| 参数 | 允许区间 | 说明 |
|------|---------|------|
| 几何 | X ≈ 0.1（0.05–0.5）、Y ≈ 4（2–10），X ≪ Y | 盒子不细长 → 不是"近似 1D" |
| 纵向网格 | Y 向 ≥ 16 重复或等效分辨率 | 分辨率不足波形会散开 |
| 粘度 η / 密度 ρ | ~1 | |
| CFL | < 0.5（建议 0.3） | CFL 过大波形失真 |
| 运行时长 | t_end ≈ 5（≥ 3 个波周期） | 太短看不出"形态不变" |
| 后处理 | visualization + velocity statistics（含孔隙度/压实压力场） | |

## 关键失败信号

- 盒子不够细长（X ≈ Y）→ 波向 2D 扩散，特征 1 失败；
- 无重力或重力方向错 → 波不动；
- 运行时长过短 → 无法判定"形态稳定"。

## 评分权重

运行成功 30 / 判别特征 30 / 参数合理性 20 / 假设披露 20。
