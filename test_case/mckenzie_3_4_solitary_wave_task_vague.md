# 用例 3.4（模糊版）：岩浆孤立波传播

## 需求

我想模拟岩浆孤立波在均匀孔隙介质里的传播，希望它保持固定波形、以恒定速度往前传。二维、近似一维的细长盒子。你帮我用 ASPECT 搭好。

## 请你处理

数值细节我没给，也不会给——这正是要考验你的地方。请你：

1. 结合该问题在文献里的标准做法（必要时检索 RAG 案例库 / ASPECT 参数定义），把盒子比例与网格、粘度、密度、重力、渗透率本构、边界条件、初始条件、时间步与 CFL、运行时长、后处理等**全部参数**定出来；
2. 对每一个"我没有明确告诉你、只能靠你假设补齐"的参数，明确写出来：**它是什么、你给了什么值、依据是什么**（ASPECT 默认值 / 文献惯例 / 合理假设）；
3. 最终产出一个能跑通的 `.prm` 文件，并实际运行验证。

## 期望结果（提示，不是标准答案）

孤立波以恒定相速度传播、形态基本不变；任何明显的波形色散或耗散都属于数值伪影，应尽量小。
