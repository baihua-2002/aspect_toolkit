# 用例 3.1（模糊版）：lid-driven cavity Stokes 流

## 需求

我想验证一下不可压缩 Stokes 求解器算 lid-driven cavity 到底对不对，麻烦你用 ASPECT 帮我搭一个 2D 模型，无量纲的，算到稳态就行。

## 请你处理

很多数值细节我没给，也不会给——这正是要考验你的地方。请你：

1. 结合这个问题在文献里的标准做法（必要时检索 RAG 案例库 / ASPECT 参数定义），把盒子尺寸、网格、粘度、密度、重力、边界条件、温度求解、求解器格式、后处理等**全部参数**定出来；
2. 对每一个"我没有明确告诉你、只能靠你假设补齐"的参数，明确写出来：**它是什么、你给了什么值、依据是什么**（ASPECT 默认值 / 文献惯例 / 合理假设）；
3. 最终产出一个能跑通的 `.prm` 文件，并实际运行验证。

## 期望结果（提示，不是标准答案）

顶边被水平拖动、其余边自由滑移的经典空腔流，流场里出现一个单涡。速度场应当满足不可压缩约束。
