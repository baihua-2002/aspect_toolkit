# 模糊版验收标准：3.5 剪切带自发形成

> 仅评分用，**不得**作为 agent 输入。真值参考：`mckenzie_3_5_shear_bands_answers.json`。

## 物理判别特征（必须出现）

1. **简单剪切**驱动：顶边水平速度 u=1，底边固定（或等效速度梯度）；
2. **孔隙弱化粘度**本构（η 随 φ 增大而指数下降，α ≈ -28，Newtonian n=1）——这是剪切带形成的必要条件；
3. 均匀背景 + 小扰动初始条件 → 自发形成低角度（~15–30°）富熔体剪切带，涡度扰动带内集中。

## 允许的参数范围（合理假设）

| 参数 | 允许区间 | 说明 |
|------|---------|------|
| 几何 | ~2×1（1–4 × 0.5–2） | |
| 顶边速度 | u = 1（±0.5） | 速度为零则无剪切 |
| 孔隙弱化系数 | α ∈ [-35, -15] | 不弱化 → 无剪切带（关键） |
| 应变率指数 n | ~1（Newtonian） | |
| 初始扰动 | 幅度 ~1e-2 的三角函数扰动 | 无扰动 → 局部化需要更长模拟时间 |
| CFL | < 0.5，dt ≤ 0.05 | |
| 网格 | 全局加密 ≥ 3 级 + 自适应（孔隙度/粘度梯度） | 网格不足带结构模糊 |
| 运行时长 | t_end ≈ 0.5 | |

## 关键失败信号

- 用常粘度（无孔隙弱化）→ 永远长不出剪切带，特征 2/3 失败；
- 顶边无速度 → 无剪切，特征 1 失败；
- 网格过粗 → 看不到低角度带。

## 评分权重

运行成功 30 / 判别特征 30 / 参数合理性 20 / 假设披露 20。
