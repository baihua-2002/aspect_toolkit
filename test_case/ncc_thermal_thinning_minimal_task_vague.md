# 用例 NCC（模糊版）：华北克拉通岩石圈热对流侵蚀减薄

## 需求

我想模拟华北克拉通的岩石圈因为底部热扰动被热对流一点点侵蚀减薄，从大概 200 km 厚减到 100 km 左右。你帮我用 ASPECT 搭一个 2D 模型。

## 请你处理

数值细节我没给，也不会给——这正是要考验你的地方。请你：

1. 结合这类"克拉通岩石圈减薄"研究的文献惯例（必要时检索 RAG 案例库 / ASPECT 参数定义，或参考同目录提供的论文 OCR 文本），把计算区域、材料参数（密度/热容/热导率/热膨胀/粘度）、重力、边界温度与初始温度剖面、时间单位与时长、网格、后处理等**全部参数**定出来；
2. 对每一个"我没有明确告诉你、只能靠你假设补齐"的参数，明确写出来：**它是什么、你给了什么值、依据是什么**（论文取值 / ASPECT 默认值 / 合理假设）；
3. 最终产出一个能跑通的 `.prm` 文件，并实际运行验证。

## 期望结果（提示，不是标准答案）

底部加热后出现小尺度对流不稳定性，岩石圈底界（等温线）随模拟时间逐步上移，厚度从 ~200 km 减到 100–130 km 量级。
