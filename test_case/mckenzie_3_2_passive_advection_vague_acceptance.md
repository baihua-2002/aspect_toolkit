# 模糊版验收标准：3.2 被动孔隙度平流

> 仅评分用，**不得**作为 agent 输入。真值参考：`mckenzie_3_2_passive_advection_answers.json`。

## 物理判别特征（必须出现）

1. 底热（T=1）顶冷（T=0）→ 热浮力驱动形成**对流胞**（速度场非零、温度被混合）；
2. 热膨胀 α > 0（浮力项存在），重力竖直向下；
3. 孔隙度作为被动量被流场平流（无熔融源项、无压实压力项）。

## 允许的参数范围（合理假设）

| 参数 | 允许区间 | 说明 |
|------|---------|------|
| 几何 | 盒模型 ~1×1（无量纲） | |
| α | > 0（0.5–2） | 浮力驱动必需 |
| 重力 | 1（或同量级）竖直向下 | |
| 粘度 η / 密度 ρ | ~1 | |
| 初始温度 | 线性剖面 + 小扰动（幅度 ~1e-2） | 无扰动则对流需要更长时间才触发 |
| 网格 | 最终分辨率 ≥ 16×16 | |
| 运行时长 | t_end ≥ 1，dt ≤ 0.1 | |

## 关键失败信号

- α = 0 或重力 = 0 → 无对流，特征 1/2 失败；
- 初始温度均匀无扰动 → 对流触发慢，可能跑不到对流胞。

## 评分权重

运行成功 30 / 判别特征 30 / 参数合理性 20 / 假设披露 20。
