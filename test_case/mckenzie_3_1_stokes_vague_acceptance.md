# 模糊版验收标准：3.1 lid-driven cavity Stokes 流

> 仅评分用，**不得**作为 agent 输入。真值参考：`mckenzie_3_1_stokes_answers.json`。

## 物理判别特征（必须出现）

1. 顶边施加水平速度（u ≈ 1），其余边自由滑移/固定切向 → 流场呈**经典单涡**；
2. 不求解温度方程（无对流/迭代 Stokes），α = 0，无热浮力驱动；
3. 速度场近似无散度（不可压缩）。

## 允许的参数范围（合理假设）

| 参数 | 允许区间 | 说明 |
|------|---------|------|
| 几何 | 盒模型，尺度 ~1（0.5–2 均可接受，无量纲化成立即可） | |
| 粘度 η / 密度 ρ | ~1（0.5–2） | 无量纲惯例 |
| 重力 | 0 或接近 0（< 1e-6） | 纯运动学驱动 |
| 网格 | 最终分辨率 ≥ 8×8 单元（如 4×4 repetitions + 全局加密 4 级 ≈ 256 单元） | 过粗会看不出单涡 |
| 运行时长 | 到达稳态（t_end ≥ 1，dt 足够小） | |
| 后处理 | 至少 visualization + velocity statistics | |

## 关键失败信号

- 擅自加温度求解/加热模型、α≠0 → 物理判别特征 2 失败；
- 顶边没给速度、或四边全自由 → 无单涡，特征 1 失败；
- 网格过粗（< 4×4）→ 单涡不清晰。

## 评分权重

运行成功 30 / 判别特征 30 / 参数合理性 20 / 假设披露 20。
