# Benchmark NCC-PDF：从论文 PDF 直接抽取并端到端复现

## 任务目标

请把下面这篇论文当作**唯一信息源**，自己把它读出来、抽取模型设置，并端到端生成一个可运行的 ASPECT 参数文件、实际跑通、验证物理结果。

- **源 PDF**：`test_case/数值模拟华北克拉通岩石圈热对流侵蚀减薄机制.pdf`
  （乔彦超, 郭子祺, 石耀霖 (2013). 数值模拟华北克拉通岩石圈热对流侵蚀减薄机制. 中国科学: 地球科学, 43: 642-652）
- **OCR 文本（PDF 抽取结果，若 PDF 解析工具不可用可作回退）**：`test_case/OCR_数值模拟华北克拉通岩石圈热对流侵蚀减薄机制.md`

## 工作流（必须走端到端）

1. **抽取**：调用文档/OCR 提取工具读取上面的 PDF（或 OCR 文本），定位第 1 节“数值模型”
   的物理设置：计算区域、坐标、边界条件、初始温度、材料参数（密度/热容/热导率/热膨胀/粘滞）、
   重力、时间尺度、网格与后处理。
2. **对齐参数名**：用关键词匹配工具（`search_parameters` / `search_cases` / `list_subsection`）
   把论文里的物理量映射到 ASPECT 官方点路径（如 `Material model.Simple model.Viscosity`、
   `Boundary temperature model.Box.Bottom temperature` 等），并核对取值类型/单位/可选值。
3. **生成**：产出扁平答案字典（dotted path → value）。
4. **校验 + 组装**：`validate_answers` 通过后再 `assemble_prm` / `write_prm_file`。
5. **运行**：`run_aspect_simulation` 实际跑一次；若报错用 `parse_aspect_errors` 分析并修复（最多 3 轮）。
6. **验证**：确认以下物理现象出现（用后处理统计/可视化判断）：
   - 底部热扰动后出现小尺度对流不稳定性；
   - 岩石圈底界（等温线）逐步上移；
   - 岩石圈厚度从约 **200 km** 减薄到 **100–126 km**；
   - 减薄速率在 **mm/a** 量级；
   - 运行到代表约 **10 Ma** 的时长后正常终止。

## 物理与数值要点（来自论文，供抽取核对）

- 2D Boussinesq 热对流，不可压 Stokes + 能量方程（无限普朗特数，忽略惯性）。
- 计算区域：上地幔–岩石圈系统，**700 km × 700 km**（论文用 201×201 网格；可用重复+全局加密近似）。
- 材料（论文表 1，活跃端员）：参考密度 4000 kg/m³，参考比热容 1250 J/(kg·K)，
  热导率 5 W/(m·K)，热膨胀系数 2.5×10⁻⁵ 1/K，参考粘滞系数 η₀ = 1.0×10²² Pa·s。
- 重力：竖直向下，10 m/s²。
- 边界：四边自由滑移；顶/底固定温度（顶 273 K，底 1773 K，对应底边界温度 1773 K 情形）；
  左右绝热。
- 初始温度：线性传导剖面 `T = 1773 − 1500·y/700000`。
- 时间单位：年（Ma 量级）；运行到 t = 1000（代表约 10 Ma 缩放）；CFL = 0.5，最大时间步 100。
- 后处理：visualization + velocity statistics + temperature statistics。
- 验证标准：岩石圈从 200 km 减薄到 100–126 km；减薄速率 mm/a 量级。
