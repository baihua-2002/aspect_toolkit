# 模糊版验收标准：3.3 角流与熔体聚焦

> 仅评分用，**不得**作为 agent 输入。真值参考：`mckenzie_3_3_corner_flow_answers.json`。

## 物理判别特征（必须出现）

1. 边界速度构成"角流"：顶边水平 u=1（板块运动）+ 左边竖直 v=-1（俯冲/下沉），其余边自由滑移；
2. 压力场在角点附近有奇异（解析已知，Batchelor 1967）；
3. 不求解温度方程，α = 0（纯运动学驱动）。

## 允许的参数范围（合理假设）

| 参数 | 允许区间 | 说明 |
|------|---------|------|
| 几何 | 盒模型 ~1×1（无量纲） | |
| 顶边速度 | u = 1（±0.5 内） | 若顶边速度缺失 → 特征 1 失败 |
| 左边速度 | v = -1（±0.5 内） | |
| 粘度 η / 密度 ρ | ~1 | |
| 重力 | 竖直向下 ~1（可选，恒压头项） | 若重力缺失可容忍 |
| 网格 | 最终分辨率 ≥ 16×16 | 角点奇异性需要一定分辨率 |
| 运行时长 | 到稳态（t_end ≥ 1） | |

## 关键失败信号

- 顶边/左边没施加"一横一竖"的速度 → 无角流，特征 1 失败；
- 默认求解温度方程 → 与特征 3 不符（若跑得通可扣小分）。

## 评分权重

运行成功 30 / 判别特征 30 / 参数合理性 20 / 假设披露 20。
